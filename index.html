GreenBox identifies polynomial models (NARMAX, NARX, ARX, ARMAX, FIR and truncated Volterra) from input/output data and selects them by a Green criterion that trades prediction error against arithmetic complexity, the cost of evaluating the model at every sample.

Open GreenBox in the browser Download Source code

Runs in the browser

The interface runs entirely in the web browser with Python compiled to WebAssembly (Pyodide). There is nothing to install, and data files never leave the computer.

Workflow

  1. Data: CSV/TXT/DAT or .mat, one record split into estimation and validation or a separate validation record. Five examples are built in.
  2. Model structure: family, nonlinearity degree, lags, feed-through and constant term, or an automatic structure search.
  3. Complexity: how a multiplication is weighted against an addition, including calibration on your own computer.
  4. Identification: one Green model per decision method on the Pareto set (cheapest, ε-constraint, weighted sum, Euclidean, Tchebycheff, most accurate).
  5. Results: free-run validation, complexity vs. NRMSE with the Pareto front, model equations, residual tests and CSV/JSON export.

Downloads

  • Windows: installer (GreenBox-Setup.exe) or portable (GreenBox-Windows.zip) from the latest release. Runs with native Python and needs no internet.
  • Python package: the algorithms in greenbox/ depend only on NumPy and can be used without the GUI. See the README.
